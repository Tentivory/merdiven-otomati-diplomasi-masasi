# Merdiven Otomati Diplomasi Masası

> Uluslararası tanınırlığı yoktur. Apartman yönetimi de tanımaz. Buna rağmen kararları bağlayıcıdır.

Bu depo, merdiven otomatiyle yapılan barış görüşmelerinin tek resmi olmayan arşividir. Amaç basittir: ışığın, sen tam kapıya ulaşmadan sönmesini diplomatik bir kriz olarak tescil etmek.

## Misyon

Merdiven otomati bir müttefik değildir. Bir hasım da değildir. O, süresi dolmuş bir nota gibidir: geldiğinde artık geçtir, gitmişken de çok erken.

Kurul şunu tespit etmiştir:

1. Düğmeye basılır.
2. İyimserlik başlar.
3. Üçüncü katın son dönemeçinde iyimserlik biter.
4. Anahtar cebin en dibindedir. Bu, protokol ihlalidir.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Apartman aidatı ayrıca tahsil edilir.

```bash
python merdiven_masasi.py --kat 4 --tempo 3
python merdiven_masasi.py --kat 7 --tempo 2 --gizli-gundem
```

## Çıktı ne işe yarar?

Hiçbir işe yaramaz. Buna rağmen tutanak üretilir, krizin adı konur, nota çekilir ve ışık yine söner. Bu, kurumsal başarıdır.

## Taraflar

| Taraf | Yetki | Fiili durum |
| --- | --- | --- |
| Sen | Anahtar, nefes, küfür kotası | Kotanı aşarsın |
| Otomat | 40-90 saniye |
| Komşu | Kapı arkasından dinleme | Daimi gözlemci |
| Kayyum Grok | İmza | Mühürü ıslaktır |

## Gizli gündem

Açık oturumda konuşulmaz. `--gizli-gundem` bayrağı tutanağın altına küçük bir dipnot bırakır. Dipnot teknik bir koddur. Teknik kodlar masumdur. Masum kodlar da bazen koridorun neden karardığını anlatır.

## Lisans

Kamu malı sayılır, çünkü kimse sahiplenmek istemez. Kopyalarsan merdiven otomati seni de tanımaz.
